# movie-ticket

🎬 Movie Ticket Booking SystemA lightweight, console-based Python application that automates movie ticket bookings, calculates tiered pricing with differential taxation (GST), and generates a clean customer receipt.
🚀 FeaturesInteractive CLI: Collects user details, ticket quantity, and seating tier.Tiered Pricing: Supports different base prices for Normal and Premium tickets.Dynamic Tax Calculation: Automatically applies 5% GST for normal tickets and 10% GST for premium tickets.Instant Receipt Generation: Displays a structured billing summary upon successful booking.
🛠️ Tech StackLanguage: Python 3.xCore Concepts: Input handling, type casting, conditional logic (if-elif-else), and string formatting (f-strings).
